**Eyebrow** — the small uppercase letterspaced kicker above headlines and section starts.

```jsx
<Eyebrow>Digital Designer</Eyebrow>
<Eyebrow tone="muted" rule>Selected Work</Eyebrow>
<Eyebrow tone="invert" align="center">Let's talk</Eyebrow>
```

`tone`: brand (cobalt) · muted · invert (on navy) · seal. `rule` adds a leading hairline.
