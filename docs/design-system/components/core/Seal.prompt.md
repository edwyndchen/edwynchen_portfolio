**Seal** — the red chop stamp (印章) used as a signature ornament beside headlines and in card corners. Keep it small; it is an accent, never a large fill.

```jsx
<Seal characters="观然" />
<Seal characters="匠心如一" size={72} />
<Seal characters="青" tone="cobalt" size={48} />
```

1–2 chars stack vertically; 3–4 form a 2×2 grid. `tone`: seal (red, default) · ink · cobalt.
