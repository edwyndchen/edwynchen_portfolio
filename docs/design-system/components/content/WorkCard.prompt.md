**WorkCard** — the signature portfolio / case-study card with the ornamental cobalt corner-frame over a porcelain body. Used in the "Selected Work" grid.

```jsx
<WorkCard
  category="Fintech"
  title="Nimbus Banking"
  description="A next-generation banking experience for a digital-first world."
  action="View Case Study"
  href="#nimbus"
/>
```

Set `framed={false}` for a plain hairline card. Pass `media` for a thumbnail. Lifts 3px on hover; arrow slides.
